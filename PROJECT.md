# PROJECT.md — Что мы строим

## Цель

Личный сайт для изучения английского языка. Пользователь — один человек (владелец).
Никакой регистрации, многопользовательских функций и публичного доступа не нужно.
Главное — удобство, простота и работающие инструменты для ежедневной практики.

---

## Функции (в порядке приоритета)

### 1. Карточки со словами
- Показывает слово (английское) — пользователь думает → открывает перевод.
- Алгоритм повторения: слова, которые запомнились хуже, показываются чаще
  (интервальное повторение, простая реализация).
- Можно добавлять новые слова вручную: слово + перевод + пример предложения.
- Можно помечать слово как «знаю» / «не знаю» / «сложное».

### 2. Чтение текстов с переводом
- Загружается текст на английском.
- Можно нажать на любое слово — появляется перевод.
- Незнакомое слово можно сохранить в словарь одним кликом.
- Тексты хранятся локально, можно добавлять свои.

### 3. Грамматические упражнения
- Упражнения на вставку пропущенного слова / выбор правильного варианта.
- Простой формат: вопрос → ответ → объяснение правила.
- Упражнения добавляются вручную или генерируются AI на заданную тему.

### 4. Отслеживание прогресса
- Сколько слов изучено / повторено сегодня.
- Серия дней (streak) — сколько дней подряд занимался.
- Простой дашборд: графики не обязательны, достаточно цифр и текста.

## Чего здесь нет (и не нужно)

- Авторизация / аккаунты
- Мобильное приложение (только браузер)
- Интеграции с внешними сервисами на старте
- Геймификация, баллы, достижения — только если я сам попрошу

## Язык интерфейса

Интерфейс на **русском**. Учим английский — но управляем сайтом на русском.

## Принципы UX

- Чисто и без лишнего. Никаких баннеров, подсказок, туториалов.
- Быстро открывается. Никаких лишних загрузок.
- Работает без интернета (данные хранятся локально в браузере).
